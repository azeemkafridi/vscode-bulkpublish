# Changelog

## 0.1.1

- The BulkPublish address settings are now read from your user settings only, so
  a project you open can't redirect your API key elsewhere.
- Sharing a selection, or a Markdown file without an image, no longer keeps the
  attachment from an earlier share.
- Instagram, Pinterest and Snapchat channels can take a video.
- A Markdown file's first image is downloaded and attached when it's on the web.

## 0.1.0

- First release: compose with live per-network character counts, publish now,
  schedule or save as draft, attach an image or video, share a selection or a
  Markdown file, sidebar of channels and recent posts with retry, and BulkPublish
  in Copilot chat.
